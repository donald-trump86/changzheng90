# 四渡赤水版式预览

本目录用于提供已验收样稿的在线预览，包含三种阅读版式、四渡赤水叙事、概略路线图与图片查看交互。预览随父仓库的正常 build 与发布流程提供，入口为 `/design-study/index.html`。页面保持静音，没有接入音频。

历史叙述的资料来源列于页面“史实与图像出处”，包括国家档案局、中共中央党史和文献研究院与新华网。两张历史照片均从父仓库已有素材按原字节复制，保持完整画面与原有比例，没有裁切或加滤镜：

- **红军集会 · 1930年代**：来源为 Wikimedia Commons [File:Long-march.jpg](https://commons.wikimedia.org/wiki/File:Long-march.jpg)。摄影者、具体年份、地点与人物未详，不能确认为四渡赤水现场。文件页标记 [PD-China](https://commons.wikimedia.org/wiki/Template:PD-China) 与 [PD-US1996](https://commons.wikimedia.org/wiki/Template:PD-1996)。
- **红六军团领导人在湖南新化合影 · 1935年11月29日**：来源为 Wikimedia Commons [File:Hongerliujuntuan.jpg](https://commons.wikimedia.org/wiki/File:Hongerliujuntuan.jpg)。摄影者未详，原始出版来源为解放军出版社1993年《中国人民解放军历史资料丛书·红军长征 图片》。此图不是中央红军四渡赤水现场，也不是1936年三大主力会师。文件页标记 [PD-China](https://commons.wikimedia.org/wiki/Template:PD-China)。

PD-China 说明中国法域的公有领域状态；红军集会文件页另有 PD-US1996，说明美国法域的状态依据。这些标记并非全球任意使用授权，其他法域的保护期限与使用限制仍须按当地法律核对。

本轮不包含杨百翰大学 Harold B. Lee 图书馆 L. Tom Perry 特藏部供图的红二十五军渡渭河与1934年中国工农红军第一次全国政治工作会议全体代表合影，也不热链这两张图。[七一网／新华社原文](https://m.12371.gov.cn/content/2026-10/22/content_517057.html)所载两图仅作研究线索，本预览未转载。

河谷图为原创生成艺术示意，不作为史料，也不复原任何具体渡口。概略路线图仅表示教学关系，不含测绘坐标或精确地形含义。
