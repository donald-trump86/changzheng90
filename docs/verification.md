## 构建版浏览器验收与复测

[../scripts/verify-browser.mjs](../scripts/verify-browser.mjs) 是单个 `async (page) => { ... }` 表达式，没有顶层模块导入、导出、驱动或启动浏览器的代码；它在页面内动态导入公开的共享故事数据。控制器已在初次提交的构建结果上，通过现有专用 Brave MCP 传入当前页面执行。修正后仍由控制器在同一 URL 完整复测。

脚本的实际配置为：

```js
const base = 'http://127.0.0.1:4173/';
const artifacts = '/tmp/dsh-browser-output/brave-agent';
```

原 brief 要求截图保存在工作树 `artifacts/`；控制器实际尝试后收到 MCP 允许目录限制的拒绝，随后明确要求只写上述已配置输出目录。本脚本遵循这一后续裁定，不通过其他路径复制被拒绝的截图。截图和 PNG 下载仅作临时 QA 证据，不声称作为工作树交付物长期保留。工作树的 `artifacts/` 仍加入忽略清单，供本地 ZIP 等非浏览器交付使用。控制器通过普通授权的本地文件操作，把表达式副本暂存至上述允许目录，再由 MCP 的 filename 参数执行；MCP 不直接读写工作树源码。

### 首轮实际结果与修正

以下来自控制器对提交 `aedba4d` 构建结果的实际执行及独立复现，本实现者没有操作浏览器。13 项中 10 项通过、3 项未通过，另有一个无脚本测试外壳触发的 favicon 404；不能据此宣称完整浏览器通过。

- 四种宽度的四章全文、展开、地图累计路线、布局检查，以及倒序/直达/快速跳转/返回/重置/刷新/未知 hash，共 8 项通过。
- 减少动态通过：最终路线立即完整，dash offset 为 0、动画名为 none。真正禁用脚本的同源 sandbox iframe 通过四章、尾声、日期方向、来源与布局检查；预期的 sandbox 脚本/自动聚焦阻止消息单独保留。
- 首轮题目检查测得实际焦点对比度 10.65449:1，但当时 `inViewport:false`。控制器独立用原生键盘复现两道题时均立即在视口内：第一题上下边界约 411–432px，第二题约 493–514px，视口高 844px。因此保留原来的可见性和对比度断言，仅增加最长 2 秒的自然焦点滚动稳定等待，以及题号、矩形、scrollY、焦点状态和等待耗时；没有强制滚动。修正后完整路径仍待复测。
- 来源对话框确有缺陷：原生 Tab 循环一次后，第 6 步 activeElement 变为 BODY。现于 [../src/main.js](../src/main.js) 对可见可聚焦控件的首尾补上 Tab / Shift+Tab 回绕，保留原生 Escape、外部点击与焦点恢复。脚本将检查加至 24 步，并在 finally 关闭自己打开的对话框，避免失败污染下一项；点击和选项操作均设了明确超时。
- 首轮 PNG 项被未关闭的对话框拦截，不能作为 PNG 缺陷证据。控制器关闭对话框后独立复测通过：实际 `image/png`、208735 bytes、签名 `[137,80,78,71,13,10,26,10]`、解码 1080×1440；下载 failure 为 null，实际“打开图片”链接在同一页进入 Blob 并由原生 img 解码 1080×1440，随后恢复普通页面。控制器查看下载图片后确认日期、方向、作者和域名正确，无裁切。[../src/share.js](../src/share.js) 未改。
- 唯一 404 的实际 URL 为 `http://127.0.0.1:4173/favicon.ico`；普通页面和已有 SVG 图标均为 200。原因是无脚本外壳 setContent 丢弃原 head。现为外壳保留真实的 `./public/favicon.svg` 相对图标引用，仍完整记录 HTTP 错误，没有过滤此错误来掩盖问题。

控制器还查看了 390px 开场、320px 第四章及 768/1440px 尾声截图。390px 换行已修好，桌面和平板整体可读；320px 中“东岸”“九溪口”“戴诗旭”断开，768px 感想末行只留“整”。本次用不换行标题词组 span、地图说明 keep-all、署名 span 及只作用于感想段落的 text-wrap:pretty 做小范围修正，历史数据和原文均未改。修正后的窄屏布局及换行效果仍待控制器查看。
