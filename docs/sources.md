## 四章日期与方向

| 章节 | 日期与方向 | 事实采用范围 |
| --- | --- | --- |
| 一渡：从土城撤出 | 1935年1月29日拂晓；西渡 | 土城战斗未获预期战果后，由土城、猿猴场（今元厚）地区渡河，向川南及扎西地区机动并整编。部署发布时间不等于全军完成渡河时刻。 |
| 二渡：重返黔北 | 1935年2月18—21日；东渡 | 在黔北兵力相对空虚、川滇敌军向扎西逼近的形势下，从太平渡、二郎滩等处回师黔北；攻取桐梓、娄山关、再占遵义是后续行动。 |
| 三渡：再向河西 | 1935年3月16—17日；西渡 | 敌方企图围歼红军于遵义、鸭溪之间，红军从茅台及附近西渡，再入川南寻求机动；不据此认定进入古蔺县城。 |
| 四渡：折返东岸 | 1935年3月21—22日；东渡 | 敌军向河西集中后，从太平渡、二郎滩、九溪口等处折返东岸，随后南下；不将3月20日部署日期当作实际渡河开始日。 |

[历史数据](../src/story.js)以两个 ISO 日历日期表示起止，一渡为同日重复；没有补充史料未统一给出的精确时刻或完成时间。两个来源 ID 表示章节的依据集合，不表示每个细节都在两篇报道中重复出现。

四渡赤水结束不等于长征结束，也不意味着渡河当天已完全摆脱所有围堵。之后南渡乌江、威逼贵阳、向云南机动，5月初渡过金沙江。1935年中央红军到达陕北与1936年三大主力会师是不同节点；时间线中的分期表示阅读范围，不把范围起点当作该项所有事件共同发生的日期。

正文将三人军事指挥小组成立时间写为“3月中旬”；可展开说明补充3月12日、苟坝的考证。该节点在二渡之后、三渡之前，不提前至遵义会议当天或一渡之前。张闻天负总责、周恩来的指挥责任、朱德的前敌司令员职务与王稼祥参加三人小组均保持可见，避免将全部军事决策归结为一人独自完成。

诗词放在遵义会议序章与四渡正文之间，是文学意象的展陈插章；不据此断言三首作于遵义至土城之间，亦不推定具体创作地点。全文按核对原文排版，不改字、不将诗句写作战场事实。

“不是‘用兵如神’，而是‘神在用兵’”是本专题创作性主题文案，页面明示非毛泽东原话。“神”指对战略判断、灵活机动与因势而变的文学概括，不作预知战场或个人神化的史实主张。五幅木刻的生成属性、原图散列和发布变体见[素材说明](assets.md)。
