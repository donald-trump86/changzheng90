# 根首页阅读动效设计

用户要求：参考 GitHub 开源动画 JavaScript 项目，明显增加当前根首页的动态体验。保留已经发布的三种阅读版式、全部历史文字和来源；直接更新根首页，不交付新预览入口或ZIP。

## 选择与范围

采用 Anime.js 的原生 JavaScript 时间线与插值能力；固定研究确认的 v4.5.0，实际核验该tag的MIT许可后才使用，本地托管原始ESM压缩包及完整许可。不上CDN、不安装框架或npm依赖。Motion有相近能力；GSAP需单独检查其标准许可，不将其等同MIT。当前需求由一套小型时间线实现，避免同时引入多库。

现有三种版式和纸本配色保持。动效概念：沿赤水河的流动，把瞬间换图变成可以看见的渡河过程；图与文字都能立即阅读，导航不锁定。

- 首屏：标题两行、日期、引导和原创河谷图分层入场，全部在1.2秒内完成。不得持久隐藏内容或增加加载屏。
- 路线：进入地图可视区、点击渡次／下一渡、展开行动或重播时，在整张地图可见之后，用约1800ms绘制当前一条连续路线；移动头点沿路径前进，终点箭头完成后显示。切章先取消旧时间线，再立即同步新日期、方向、地图与正文。新增“重播路线”。
- 章节：当前正文立即切换，标题和段落从当前呈现状态短距离入场，约300–500ms；快速前后切换不排队、不恢复旧内容。保持原有可中断、保留速度的details弹簧。
- 河流与滚动：独立河面流线；仅原创河谷插画轻微视差／缓慢漂移。保留历史照片完整画面，不给照片加滤镜或裁切。页面有实际阅读进度反馈，不劫持滚轮或拉长页面。
- 入场：时间线节点按顺序显现，后续历程及档案图文分别入场，避免全页同一种淡入。所有默认HTML可见，缺少模块／IntersectionObserver也能阅读。
- 控制：页首“暂停动画”按钮，最小44px目标；暂停、系统减少动态、隐藏页面、pagehide必须取消正在运行的动画，完整显示文字、图片和路线。恢复后允许重新播放，但不播放未完成的旧章节。系统减少动态不可被按钮越过。

## 集成与边界

根HTML仅增加控制、SVG头点／流线、样式及模块引用、章节与版式变化通知。新模块监听document的 `chishui:chapter`（detail.number）及 `chishui:layout`，独立管理所有Anime实例和滚动／观察器；首次加载从可见DOM初始化，不依赖事件恰好先发生。不要依赖隐藏全局状态、账号、存储或网络API。所有失败必须静态可读。

保留所有章节原文、历史日期／方向、图像原字节／图注／来源、图片对话框焦点、无个人署名以及无脚本全文。原版src模块、研究样稿和域名／Cloudflare设置不变。

## 实际验收

320／390／768／1440宽度、三种版式无溢出和遮挡，正文至少16px、按钮至少44px；实际量测路线strokeDashoffset及头点坐标随时间变化、重播／快速切换取消、原生点击后整图可见。截图比较首屏及阅读状态。实际量测河流、视差、图文入场进度；暂停／减少动态后没有本模块运行中的实例，路线完整，正文可读。回归details中途反向、来源与图片对话框、脚本禁用全文、模块加载失败降级。使用唯一专用Brave MCP；禁用独立浏览器／CDP／资料目录。只记录实际证据，不以animation-name代替运行验证。

部署通过明确资源白名单，在仓库子路径实际请求模块、CSS、库及许可；检查内容和类型。正常快进推送main与gh-pages，核对实际构建为本次根首页提交。
