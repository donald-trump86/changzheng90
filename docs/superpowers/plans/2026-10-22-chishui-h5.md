# 四渡赤水互动 H5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成可在手机阅读、可回看四次渡河路线且能导出纪念卡的原创静态 H5。

**Architecture:** 无运行时依赖的 HTML/CSS/ES modules。史料数据与纯状态逻辑独立；SVG 地图与 DOM 控制器消费同一章节数据；标准 Node 工具生成 dist/。所有发布操作留至用户看过最终成品并确认之后。

**Tech Stack:** Node >=22、HTML、CSS、JavaScript、SVG、Canvas、Node test runner；浏览器检查使用已有 Chromium/Playwright 工具，若缺少可仅安装开发依赖。

**Spec:** docs/superpowers/specs/2026-10-22-chishui-design.md

## Global Constraints

- 作品标题为“四渡赤水”，副标题“为什么这样走”。
- 署名戴诗旭；预定域名 changzheng90.luvch1nabest.me。
- 四章日期：1935-01-29（一渡开始）、1935-02-18—21、1935-03-16—17、1935-03-21—22；不得把四渡当成长征终点。
- 不虚构对白、心理、精确兵力、历史结局或测量数据；事实由两个实际读取的官方来源支撑，文案用自己的表达。
- 无运行时依赖、API、账号、数据库、远程字体、CDN、统计、自动音视频；全部站点资源相对路径。
- 地图为原创概略示意，西渡/东渡方向合理，明确标注“路线为概略示意”。
- 正文至少 16px，触控区至少 44px；320/390/768/1440px 无横向溢出；支持键盘和 prefers-reduced-motion；无 JS 可读全文。
- 每任务子代理实现、测试、自审、提交；新审查代理检查规范与质量，最终再检查整个分支。
- 不创建远程仓库、不推送、不启用 Pages、不改 DNS；先交付可预览的最终本地内容。
