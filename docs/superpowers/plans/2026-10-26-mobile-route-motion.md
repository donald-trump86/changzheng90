# 手机路线动画与阅读体验修改计划

**目标：** 手机阅读每一渡时可看到该阶段路线从起点展开，并能重播；滚动保持原生触屏手感。

**范围与设计：** 保留现有 SVG 地图数据、木刻图像、章节顺序及两套字体。不改变史实与音乐。沿用纸色 `#f7f7ef`、墨色 `#111711`、朱红 `#751b19`、地图纸 `#e0e8db`、河色 `#365d67`；仿宋负责标题与诗词，系统字负责正文和控件。

手机构图：`渡次与日期 → 阶段地图与重播 → 局势/选择/结果`。专题继续使用大幅木刻与舒展正文，平板窄列改为可读段落。核心动作是沿真实概化路线演示行军，不额外引入装饰动效。

方案选择：在既有 editorial-motion 生命周期内增强分章 SVG，采用临时 SVG 遮罩保留各渡虚实线型；相比把桌面地图搬入手机，原地增强不造成布局搬移。相比为整页加触屏平滑滚动，保留原生惯性更能跟手。这是本轮实现判断。

- [x] 在地图可见时播放一次路线揭示与行军点，支持每图重播。滚出视野、暂停、减少动态、切后台或销毁后恢复完整静态图；无 JS 仍能阅读。
- [x] 阅读进度直接跟随滚动帧，触屏取消环境漂移与不必要的文字升场；桌面保留已有交互。
- [x] 调整手机/平板专题图文节奏与正文列宽，保持纸墨风格。
- [x] 添加生命周期/线型保留回归测试；运行全套测试和构建；使用同一 Brave 浏览器验证 390、768、1440 宽度、快速滚动与减少动态。

**验收重点：** 四张地图分别可动且不串图；二三四渡原虚线仍保留；重播可打断；不因滚动隐藏标题和正文；没有页面横向溢出。仅本地修改，发布另按用户确认。
