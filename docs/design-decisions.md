## 同一路径上的绘制与终态

每个 `[data-route]` 仅有一个连续 stroked SVG path。删除 `routes[].arrow` 与 `crossing-arrow`；完成时在主路径终点显示 marker。绘制中隐藏终点 marker，移动圆点通过该 path 的 `getPointAtLength` 同步定位于描线头部，不再循环。

路线只由实际“展开路线”或“重播路线”触发。手机原生点击可能先把地图滚出屏幕，应用会先用即时滚动把整张地图置入视口，保留触发按钮焦点；经过两次 requestAnimationFrame 并重新确认地图完整可见，才开始1900ms描线。重播复用同一 DOM 路径；开启动画本身不自动重播。历史章节采用低对比虚线保留方向信息。

每次 render 递增 generation 并取消待处理 frame，防止快速／反向导航、返回开场、重置留下旧路径动画。音乐模块继续独立管理 motion 设置；地图仅观察 body 的 `data-motion`。用户暂停、系统 reduce、pagehide 或页面隐藏会结束为完整路线、移除描线点，而不是停在半截。无脚本与初始化前默认静态。

地图的河流、山形、渡口、方向、日期和叙事保持原样；路线是原创概略示意，不代表精确行军轨迹或真实地形。历史事实与“作者解读”保留原有边界。
