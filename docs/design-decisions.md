# 四渡赤水：实现中的设计取舍

第三版采用用户指定的 split-stage／map-first 方向，种子 `2094615674`。用户已否定旧 name-as-monument 大标题；本轮直接实施紧凑标题与地图优先，不重复设计确认。

## 紧凑开场与阅读布局

保留朱红 `#a51c27`、米白 `#fff4df`、金黄 `#fdcf30` 和系统宋体／黑体。桌面 h1 为36–56px，手机34px。移除独立山川横幅与重复阅读入口；开场只有一个“开始阅读”，音乐／动画控制保持可用，地图成为主体。桌面采用地图与叙事并列，地图 sticky；手机上下排列，无占满屏幕的固定遮挡。

标准党徽仍为带明确图注的静态教育内容，原始420字节 SVG、比例与金黄色不变，独立不透明背景保证无附加线条穿过。党徽不用于 favicon、控件或纪念卡。来源和许可见[素材清单](assets.md)。

## 同一路径上的绘制与终态

每个 `[data-route]` 仅有一个连续 stroked SVG path。删除 `routes[].arrow` 与 `crossing-arrow`；完成时在主路径终点显示 marker。绘制中隐藏终点 marker，移动圆点通过该 path 的 `getPointAtLength` 同步定位于描线头部，不再循环。

路线只由实际“展开路线”或“重播路线”触发。手机原生点击可能先把地图滚出屏幕，应用会先用即时滚动把整张地图置入视口，保留触发按钮焦点；经过两次 requestAnimationFrame 并重新确认地图完整可见，才开始1900ms描线。重播复用同一 DOM 路径；开启动画本身不自动重播。历史章节采用低对比虚线保留方向信息。

每次 render 递增 generation 并取消待处理 frame，防止快速／反向导航、返回开场、重置留下旧路径动画。音乐模块继续独立管理 motion 设置；地图仅观察 body 的 `data-motion`。用户暂停、系统 reduce、pagehide 或页面隐藏会结束为完整路线、移除描线点，而不是停在半截。无脚本与初始化前默认静态。

地图的河流、山形、渡口、方向、日期和叙事保持原样；路线是原创概略示意，不代表精确行军轨迹或真实地形。历史事实与“作者解读”保留原有边界。

## 音乐、本机输出与访问

本地《国际歌》CC0数字器乐文件和音乐控制逻辑未改；默认关闭、独立点击播放、后台暂停、错误重试维持原行为。静态党徽和音频的文件字节均未改。1080×1440本机 PNG、真实原生保存／打开图片后备、两道理解题、来源对话框与全文 noscript 维持原逻辑，无个人署名。

没有增加依赖或改变构建／服务器／部署模块。实现者仅操作允许的本地文件及临时测试端口，未使用浏览器、客户端、CDP、资料目录、网络或新持久服务。
