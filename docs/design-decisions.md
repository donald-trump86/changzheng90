# 四渡赤水：实现中的设计取舍

本轮执行已批准的[红色舞台设计](superpowers/specs/2026-10-22-red-stage-design.md)与[实施计划](superpowers/plans/2026-10-22-red-stage.md)。沿用原 name-as-monument 方向及种子 `1099683438`；用户明确的红背景、动画、音乐、标准党徽和无个人署名要求替代此前的冷色与稀疏动效取舍。

“四渡赤水”四字仍占据近乎整行，中文宋体标题与本地黑体正文形成层次。页面以朱红 `#a51c27` 作整页基底，米白 `#fff4df` 为正文，标准金黄色 `#fdcf30` 为重点；深红 `#871521` 托住正文说明和地图，山形采用三层深浅红。红背景也延续到弹窗、尾声和本机 PNG，避免只在控件上换色。系统字体无需在线服务，真实字面与排版待控制器四种宽度复核。

## 开场与静态党徽

大标题之后是一幅横向山川场景：三层山形错时进入，云线轻移，河水金线连续推进。移动端保留有高度的场景与完整标题，阅读入口仍在标题旁。地图与正文在桌面并列，窄屏依次排列。

标准党徽作为开场党史学习内容的独立 figure 展示，附明确图注；原始 SVG 字节、几何、比例与金黄色不变。党徽保持静态，figure 用不透明深红底和留白挡住场景线条，避免从透明负形中透出附加笔画；动效属于另一个原创 SVG 场景，不作 favicon、交互控件或纪念卡装饰。具体来源、许可与哈希见 [素材清单](assets.md)。

## 原创地图与可停止的动态

地图保留三层山形、单条弯折河流与具名渡口。图中以上北下南的概略排列呈现元厚、土城、太平渡、二郎滩、九溪口与茅台；扎西、川南及黔北作为方向参照。渡口不按比例定位，线条不代表精确行军轨迹，山形不代表真实地形。路线仍以文字、箭头和章节说明共同表达方向；历史事实、日期与作者解读没有重写。

本章展开后先描绘完整金色路线，再由移动点沿路径反复前进；先前各渡用低对比虚线留痕。地图云线与开场云水也持续运动，使读者可见地感知动画。路线和地图的语义状态仍由原状态模块控制。

“暂停动画”与音乐互相独立。暂停会移除动画并呈现完整静态终态：路线 dash offset 为 0、行军点到达终点、文字完全可见。系统 `prefers-reduced-motion: reduce` 优先，禁用动态按钮并立即显示完整终态；无脚本与控制器尚未初始化时也默认静态，避免没有可用暂停入口的持续运动。

## 音乐与本机输出

音乐使用本地《国际歌》MuseScore 数字器乐复刻的真实 CC0 音频；默认关闭，只有独立点击音乐按钮才播放，不随开始阅读、重置或章节切换触发。控制器管理真实 HTMLAudio 的播放 Promise、播放／暂停状态、加载错误与重试；后台和 pagehide 自动暂停，返回后需再点击。素材文件保持原样，默认元素音量 1，不操作系统音量。

`createMediaControls({ audio, musicButton, motionButton, root })` 返回 `{ destroy() }`，统一移除本模块监听器、使待处理播放请求失效并暂停音频。场景动态按钮与系统减少动态设置均不改变音乐状态。

纪念卡继续本机 Canvas 输出，使用红底、金色标题与完整历史日期，保留原创简化四次跨河示意、主题和预定域名。当前界面、来源对话框、无脚本全文、卡片画面及 alt 均不附个人署名。每章与尾声的“作者解读”标签仍保留，明确解释与史料事实的边界。音频的作曲者、上传者和许可信息属于真实素材来源说明。

## 包装与验证边界

构建清单精确列出站点 HTML、六个源码文件、原创 favicon、标准党徽、MP3 与 CNAME；不复制文档、测试、私有报告或任意 MP3。相对路径继续支持根路径与仓库子路径。预览服务器提供 MP3 MIME、Accept-Ranges、单段字节 Range、HEAD 与一致的 416，不添加外部依赖。

本实现者只做授权的本地文件与 Node 检查，未启动浏览器、CDP 或新驱动。浏览器验收扩展现有单个 supplied-page async 表达式，保留原 13 组语义检查，并增加动画进度、完整暂停、标准静态党徽、红色背景、真实静音音频解码与时间推进、失效音频后重试等证据。控制器将检查 320／390／768／1440px 的真实排版并给出本轮截图结论；旧版通过记录与评分不适用于本轮。实际状态见 [验证记录](verification.md)。
